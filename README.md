# Guardian Now

Create a web application for A.A private security

requirements 
1. Speed tracker with location to see if a person was travelling at a high speed and then stopped immediately, which could signal a crash
2. shake report if the phone shakes send a notification to disable the notification because if not in 7 mins the phone will call the members of the security team to the location of the phone
3. have a big red button for immediate help request 
4. have a contacts section if a person is in need , the contacts will get a notification and location 

Design Requirements
Mobile-friendly design • Modern interface • Easy navigation • Responsive layout
